## 2. Decisiones tomadas

| Tema | Decisión | Motivo |
|---|---|---|
| Nodos del grafo | **Roster fijo ~20 países** (`NODOS_ACTA`) | Índices estables entre snapshots |
| Aristas | **Dirigidas** Actor1→Actor2, agregadas por par/día | Conserva quién actúa sobre quién (CAMEO) |
| Librería GNN | **PyTorch Geometric** (GATv2) | Encaja con GAT/HATS de la tesis |
| Periodo piloto | **2 semanas previas al 24-feb-2022**, predicción del 25 | Invasión de Ucrania = shock geopolítico |
| Target (etiqueta) | **close-to-close**: `signo(close_D − close_{D-1})`, banda τ=0.1% | El shock geopolítico pega de noche (overnight) |
| Resolución | **Diaria** (solo Open/Close) | Yahoo no da intradía para 2022 (>730 días); GDELT 1.0 es diario igualmente |
| Alineamiento snapshot↔sesión | **B**: 1 grafo por sesión de mercado, agregando finde/festivo | 1 grafo : 1 etiqueta, capta acumulación de fin de semana |
| Estructura de carpetas | `src/datos · modelo · entrenamiento` + `notebooks/` | Propuesta del usuario |

### Nota conceptual: cómo se relacionan apertura y cierre
- Tres retornos encajados: **gap nocturno** (`open_D/close_{D-1}`), **intradía**
  (`close_D/open_D`), **close-to-close** (= gap + intradía).
- Regla anti-leakage: prediciendo *antes de la apertura* de D, `open_D` y `close_D`
  están en el futuro → **no** pueden ser input. `open` se usa solo como feature
  retardada y diagnóstico.

### Diseño del grafo (`grafo.py`)
- **Nodos**: 20 países, orden canónico `NODE_CODES` (sorted), índice estable.
- **Features de nodo (9)**: `log_n_eventos`, `frac_como_actor1`, `mean_goldstein`,
  `mean_avgtone`, `log_sum_mentions`, `frac_q1..q4` (QuadClass).
- **Aristas dirigidas roster→roster, features (8)**: `log_n_eventos`,
  `mean_goldstein`, `mean_avgtone`, `log_sum_mentions`, `frac_q1..q4`.
- **Modelo**: `GeoEncoder` (GATv2 ×2, usa `edge_attr`) → `global_mean_pool` →
  embedding de grafo → cabeza triclase. `fin_dim` reservado para fusionar S&P 500.

## 6. Limitaciones conocidas

- **Dataset diminuto**: 9 train / 1 test → sirve para validar fontanería, no para
  métricas fiables. Fuerte desbalanceo (8 baja-ish / pocas sube / 1 neutro).
- GDELT 1.0 es diario → no hay event-study intradía con esta fuente.
- El modelo es un **GATv2 plano**: faltan la **HGNN jerárquica** y el **decay de
  Hawkes** mencionados.
